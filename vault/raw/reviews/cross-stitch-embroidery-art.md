### RobTKE397 (2020-04-01) - 5★ [App Store]
- **Version:** 2.2.5
- **Comment:** **Great features for pattern making**
For Customers:
The generator is great overall, and does a great job with choosing the correct DMC colors to use. I also like the ability to toggle on/off the grid for it, as well as which color you want active. It makes it a lot more manageable when you select one color, and the app will “dull” out the other colors so you can really focus on the color section you are working on and then change to a different color and that one will be highlighted for you. I’m currently using the free version, so I can only make 1 pattern at a time, so I chose the biggest option and the highest pixel count. Well the App creates a 10 count grid, which would be too massive to create on actual cloth, so I shrinked it and used 14 count Aida Cloth instead of a 10 count (for people who don’t know, 10 count means 10 stitches per inch and 14 count is 14 stitches per inch). With the image I’m making, even after going from the 10 to the 14 count, it’ll still be 36in long by about 20in wide, so yeah, massive haha. Once I finish this pattern I’ll be able to make another, and I can try to play more with the dimensions when it comes to making smaller art and I’ll do a review on that.

Note for the Developers:
It would be great if I could edit my pattern. Sometimes the software choses certain colors that I don’t want in the pattern and want to switch with a different color or does the outline of my image in a way I’m not fond of and I want to change the grid. I’m not sure if that’s available in the purchased version (I didn’t see a note where it said that? Unless I’m blind and missed it?) But if that isn’t an option right now, that would be a great addition.
