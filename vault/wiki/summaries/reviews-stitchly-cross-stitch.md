## Öne Çıkan Kullanıcı Deneyimleri

### Suemike09 (2026-06-13) - 5★ [App Store]
> **Best Cross Stitch App**
I love this app. My favorite feature by far is when you can select the colors you don’t want. But before you do, you can see where that particular color is on the chart which helps determine if you can get away with not having that color or not. I already have a program on the computer which I have had for years and done loads of charts/cross stitch on there. I have to say this app surpasses that easily! The fact that you can upgrade to the paid version for one price and not have a subscription is the best!

### Jen in Germany (2026-06-09) - 4★ [App Store]
> **Really good app, not perfect**
I’m really enjoying this app, but there are a few improvements I would make if possible.  One simple one would be to “highlight” everything of a single color when I choose that color, especially when importing a photo.  It would make it far easier to determine if a color should be eliminated.  Occasionally there are only a few stitches in that color but they are really important to the stitch out (highlights in eyes comes to mind).

### vgcygcfuugcitc (2026-05-29) - 2★ [App Store]
> **Changed PDF usage**
I’ve used Stitchly for years to keep up with a lot of different projects. They now give a message when you try to upload a file that says they are designed for creating your own patterns, and won’t let you upload pattern pdfs to work on. I have tons of files I work out of that were uploaded from pdfs, including an 80 something page Zelda Tapestry pattern. This change really makes the app useless for how I use it unfortunately. I’ve never had any luck using the app to “design” my own patterns, but to keep up with my progress on my patterns, for knitting, crochet, cross stitch, etc.

### LynneChick (2026-05-26) - 4★ [App Store]
> **From a Slightly off-label user…**
I use Stitchly to create charts for single unit drawloom weaving.  I love all the cut, copy, paste, flip, and so on.  My only dream function would be the ability to print landscape, as well as format, so my chart squares print out larger; I don’t mind multiple pages.  My current chart maxes out the size limit, so I’m weaving halfway in and then back.  Ok, another request - being able to highlight (vertically) every 5 or 10 columns, because I am working across an entire row picking drawcords (all 120 of them) and it makes it easier to keep track of where I am.

### Toyy5starr (2026-05-23) - 5★ [App Store]

This app is so fun so amazing. I get my patterns done and I enjoy it while I do it so thank you. Spiritually for the amazing work that you guys let us do as creators. Thank you so much.
