# Keep stitch rendering off the network and background work

Stitch Action and Undo Action commit to the Local Identity Namespace and update the visible materialized Session Progress before any network or cloud-sync work. Pan, Anchored Zoom, Stitch Sweep, Thread Palette interaction, and Remaining Cell Locator read only verified local Pattern and progress data. No API request, Commerce Ledger check, Progress Sync acknowledgement, image conversion, Pattern Artifact decompression, or general database reconciliation may block that interaction-critical path.

The release performance scenario uses the oldest supported iOS and Android reference devices, a maximum `300×300` Pattern, a 60-color Thread Palette, completed-cell density representative of late play, and an active background sync queue. Stitch and Undo input-to-visible-state must remain at or below 50 ms at p95. Viewport pan, Anchored Zoom, and Stitch Sweep target 60 frames per second. A 15-minute sustained run must not reach the platform's serious or critical thermal state; frame pacing and heat are measured on hardware rather than inferred from a short emulator run. Failing the reference scenario blocks release or requires an explicit scope decision, not a silent device-specific degradation.

Rendering uses viewport culling, bounded caches, incremental progress materialization, and background scheduling appropriate to the chosen React Native renderer. Heavy artifact verification, sync compaction, preview work, and queued processing yield during active gestures and resume afterward. CrossCraft background-service behavior may inform retry and lifecycle handling, but this game owns the implementation, telemetry, budgets, and independent backend contracts.

We accept performance fixtures, physical-device CI or release testing, gesture-aware background scheduling, renderer complexity, and a conservative maximum Pattern size in exchange for protecting the calm stitching loop from frame stalls, heat caused by unnecessary full-grid work, and false connection dependencies during play.
