# Separate public creator profiles from private account identities

A Registered Account remains the private owner and authentication identity for player content, balances, moderation history, and purchases. Before creating its first Catalog Submission, the account must create one Public Creator Profile containing a globally unique username the player cannot change, plus an editable display name and optional avatar. Moderator Username Reset is the sole exceptional replacement path for a violating value. Community Patterns reference that shared profile as their creator identity, so current profile values appear across all of the account's existing Patterns without mutating their immutable Pattern snapshots. Previous display names, avatars, and moderator username resets, including actor, reason, and timestamp, remain only in a private append-only Creator Profile Audit. The catalog and other players never receive the account's email address, authentication-provider identifiers, Apple or Google profile data, or profile audit history.

The first release does not require routine human Profile Review before creating the profile or publishing a later display-name or avatar change. Instead, every candidate passes a server-side Profile Safety Check: username and display-name text are validated against reserved-name and profanity rules, and an optional avatar passes automated image safety moderation. A failed candidate is not published and returns a user-facing reason without changing the last accepted public values. A passing candidate becomes public immediately and does not wait in the Catalog Review queue.

Every Public Creator Profile also provides an in-game Profile Report action for Registered Accounts. A report is unique per submitting account and open Profile Investigation, so repeats during that case return the existing report rather than multiplying it. After closure, a newly published profile state or materially new evidence may create a new rate-limited case. One or more reports start a human Profile Investigation, but reports never hide, edit, or restrict the profile automatically. This reactive investigation is distinct from the routine Profile Review gate that the first release intentionally does not have. The moderator may close reports without action, apply Profile Remediation by resetting a violating display name to a safe default and removing the avatar, use Moderator Username Reset for a violating permanent username, or impose Creator Restriction for repeated or serious violations.

Creator Restriction masks the public identity as `Restricted Creator`, removes its public avatar, and blocks further profile changes and new Catalog Submissions. It does not delete the Registered Account or remove existing Community Patterns. Existing Patterns retain their catalog availability and sessions unless the content of a specific Pattern independently warrants Safety Removal. Profile Remediation is narrower: it preserves the permanent username and lets the player submit future display-name or avatar values through Profile Safety Check. Moderator Username Reset is the sole exception to username permanence: an authorized moderator replaces a violating value with one safe system-generated username while preserving the profile's opaque identifier, Catalog Share Links, ownership, and private audit history; the violating value is never reused.

The restricted account may create one Creator Restriction Appeal against the same decision and moderation record. The restriction remains fully effective while the appeal is open, and the appeal is assigned to a different moderator when operationally possible. Acceptance restores the last safe Public Creator Profile values together with profile-editing and Catalog Submission access; if no safe historic username exists, Moderator Username Reset supplies one before restoration. An upheld restriction is final. Profile Remediation has no separate appeal because the player can submit new compliant display-name and avatar values through Profile Safety Check.

We accept a separate profile record, permanent global username allocation, avatar storage, shared-profile lookups, automated-safety false positives, reactive human-investigation work, profile-level enforcement state, a private audit history, and the absence of a routine human approval gate in exchange for stable public attribution and immediate safe profile updates that do not leak sign-in credentials or provider identity. Display-name and avatar edits can propagate without rewriting immutable Community Patterns, while retained prior values and player reports support moderation investigations. Separating profile enforcement from Pattern removal avoids destroying valid shared content or player progress because of creator-identity misconduct. Authentication changes therefore do not alter catalog ownership, and a player can participate publicly without exposing the private identity used to access the account.

Account Deletion is separate from moderation. Account Closure Hold reversibly hides the profile and owned Community Patterns during Deletion Recovery Window. Finalization deletes public profile values, retains minimal username and opaque-identifier reservation tombstones for the life of the service, replaces attribution required by existing withdrawn sessions with Deleted Creator, and keeps detailed pseudonymous moderation evidence only for its bounded policy or legal period. Creator Restriction never substitutes for deletion, and deletion never erases an active safety or legal record prematurely.
